## 📋 Overview

This repository contains a highly detailed document covering **48 different types of Cyber Security Threats**. The threats are categorized into 15 major sections, making it easy for students and professionals to understand the landscape of modern cyber attacks.

---

## ✨ Key Categories Covered

* **Malware Threats:** Virus, Worm, Trojan, Ransomware, Spyware, Rootkit, Keylogger.
* **Phishing Attacks:** Email Phishing, Spear Phishing, Whaling, Smishing, Vishing.
* **Social Engineering:** Pretexting, Baiting, Quid pro quo, Tailgating, Shoulder Surfing.
* **Password Attacks:** Brute-Force, Dictionary, Credential Stuffing.
* **Network Attacks:** DoS, DDoS, Man-in-the-Middle (MitM).
* **Injection & Spoofing:** SQL Injection, XSS, IP Spoofing, DNS Spoofing.
* **Advanced Threats:** Zero-Day, Advanced Persistent Threat (APT), Supply Chain.
* **Cloud Security:** Misconfigured Storage, Stolen Credentials, Insecure API.
